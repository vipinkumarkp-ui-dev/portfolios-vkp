# VIPINKUMAR K P — Portfolio (No Photo Edition)

Responsive one-page portfolio built from the updated resume and latest skills.

This edition intentionally uses a visual initials/orbit hero instead of a profile photo, so it works well for applications where a photo is not preferred.

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Latest stack included
React.js, TypeScript, Tailwind CSS, Sass, PostCSS, modern React libraries, PostgreSQL, Swagger, Cloudflare, Go basics, Stripe payments/gateway management, PostHog, and AI tools/model study including ChatGPT, Gemini, Claude, Antigravity, Windsurf and Devin.
